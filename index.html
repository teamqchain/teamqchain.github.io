Architected for Post-Quantum Resilience

Conventional PKI relies on RSA and ECC. Shor's algorithm running on fault-tolerant quantum hardware will break these standards. QChain replaces classical primitives with lattice-based mathematics.

Lattice-Based Authenticity

Signatures generated with ML-DSA-44 (Dilithium) are anchored on Hyperledger Fabric. Mathematical hardness based on Module Learning With Errors (M-LWE) guarantees degrees cannot be forged.

Zero-Knowledge Disclosure

Credentials commit to salted per-field SHA3-256 hashes. Holders selectively present only chosen attributes (e.g. GPA or graduation date) without revealing sensitive demographic PII.

Decoupled Off-Chain IPFS

To avoid ledger bloat from post-quantum signature sizes, full encrypted credential bodies reside off-chain on content-addressed IPFS, keeping the Fabric state lean and scalable.

Verification Pipeline

From cryptographic issuance to zero-trust verification in four decoupled phases.

01

Canonical Issue

Issuers define credential schemas and generate salted field commitments (SHA3-256) via the authenticated QPortal.

QPortal · RBAC
02

Quantum Sign

The organization signs the credential commitment hash with ML-DSA-44 and commits state immutably on Hyperledger Fabric.

ML-DSA-44 · Fabric
03

Hybrid Encrypt

The credential body is wrapped via ML-KEM-768 + AES-256-GCM and stored on IPFS; only the holder holds the decryption key.

ML-KEM-768 · IPFS
04

Dual Verify

Verifiers validate both the issuer's signature on-chain and the holder's single-use presentation signature with zero server trust.

Zero-Trust · QR / OTP
